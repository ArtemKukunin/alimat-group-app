# ALIMAT Connect — public demonstration

Copyright © 2026 Artem Kukunin. All rights reserved. See [LICENSE](LICENSE).

This repository contains **only a browser demonstration** with fictional data.
It does not contain the production application source, database schema, backend,
credentials, or real employee data. It does not send messages between people.
The administrator demo button is an unrestricted preview, not an admin login.
The employee referral form does not transmit or store the candidate's details
in this public demo. Its project selector shows interests, not confirmed vacancies.
The home screen also previews day off, vacation, sick leave, complaint, and
coordinator-contact requests. Demo requests stay in the visitor's own browser.
The legal partner in this demo is fictional. A live legal request is rejected
unless a verified partner account has been assigned on the server.

Open [the demo](https://artemkukunin.github.io/alimat-group-app/) after GitHub
Pages is enabled. The JavaScript delivered to a browser is necessarily visible
to site visitors. No license to copy or reuse it is granted.

Not ready for live employee use: production permissions and data handling still
require security review and integration testing.
